## For the printer

- Send the **SVG**. The PNG is for on-screen proofing.
- Error correction **H** (30%), quiet zone **4 modules** — already in the file.
- **Do not crop to the black edge.** The white margin is part of the symbol.
- **Do not recolour.** Pure black on pure white; the brand orange does not
  carry enough luminance contrast to scan reliably.
- Print at 20 mm or larger on the pouch, and test-scan the proof.

## If a slug ever changes

Codes already printed cannot be changed. Keep the old slug working —
`lib/products.ts` is where these URLs come from, and this script refuses
to build a code for a slug the catalogue does not define.
